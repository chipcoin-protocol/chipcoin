# Test vector licensing scope

The machine-readable `*.json` vectors in this directory are excluded from
the Chipcoin Core MIT grant. This includes the synthetic Stratum vector
provided by Crypto Connection. Permission to publish a vector is not an MIT
license grant. See [Core license scope](../../licensing/LICENSE_SCOPE.md).

Original Chipcoin verifier scripts in this directory are covered by the Core
MIT license unless a particular file carries a different notice.
