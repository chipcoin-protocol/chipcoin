# Public Mainnet Genesis Finalization Runbook

This procedure remains blocked until the founder approves one exact UTC Unix
timestamp. It never uses a runtime-generated timestamp and does not alter the
approved difficulty or economic parameters.

## Preconditions

1. Record the approved timestamp in UTC and Unix form. Confirm it is not later
   than the intended public start and assess its effect on the first retarget.
2. Freeze the source commit and verify `chipcoin-mainnet-1`, magic `c0897c0d`,
   bits `0x1d1399ad`, zero genesis reward, and the exact 37-byte UTF-8 message.
3. Choose an empty output directory on an offline host. Record Python, OS, CPU,
   source commit, lock hashes, and the worker count.

## Primary Build

Run the canonical builder with parallel workers. Parallelism only partitions
the nonce search; batches are evaluated in nonce order, so the selected nonce
is still the lowest valid nonce and is identical to the serial result.

```bash
python scripts/build-public-mainnet-genesis.py \
  --timestamp APPROVED_UNIX_TIMESTAMP \
  --workers "$(nproc)" \
  --output-dir /secure/genesis-primary \
  --acknowledge-founder-approved-timestamp
```

The output contains block hex, manifest, constants and checksums. Do not edit
any generated file.

## Independent Reproduction

On a second clean checkout and preferably a second host, repeat the build with
a different worker count. Compare every generated byte and checksum. Then run:

```bash
python scripts/verify-public-mainnet-genesis-independent.py /secure/genesis-primary
sha256sum -c /secure/genesis-primary/SHA256SUMS
diff -ru /secure/genesis-primary /secure/genesis-secondary
```

The independent verifier uses only the Python standard library. It parses the
transaction and header, recomputes TXID, Merkle root, double-SHA256 block hash,
compact target and PoW, and asserts no inputs, outputs or initial supply.

## Freeze And Incorporation

1. Review and approve timestamp, nonce, block hash, block hex and all checksums.
2. Replace only the pending canonical constants in
   `src/chipcoin/consensus/genesis.py` with the reviewed block hex/hash.
3. Replace pending values in the public genesis manifest and configure the
   exact hash in node, miner, wallet, reward tooling and Explorer artifacts.
4. Run the complete 98-gate matrix from `public-mainnet-rc-revalidation.json`.
5. Produce immutable artifacts and a new RC only after all mandatory tests pass.

Any mismatch stops finalization. Never select another nonce, timestamp or hash
to make two outputs agree, and never publish a TEST-ONLY rehearsal identity.
